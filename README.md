# 🎮 Life RPG

Turn your daily goals into a game! 🚀

Life RPG is a gamified productivity app that transforms everyday tasks into quests. Complete quests, earn XP, level up, unlock rewards, and upgrade your character.

## ✨ Features

- 📝 Create daily quests/tasks
- ⭐ Earn XP and points by completing quests
- 📈 Level up as you progress
- 🎁 Unlock rewards
- 🧙 Character progression
- 🛍️ In-app shop
- 🎉 Level-up celebration
- 🎨 RPG-inspired UI
  This is built for a hackathon.
