# 🎮 Life RPG

Turn your daily tasks into quests and level up your life!

## 🚀 About

Life RPG is a gamified productivity app that turns everyday tasks into RPG-style quests. Complete tasks, earn XP, gain points, level up, unlock rewards, and upgrade your character.

## ✨ Features

- 📝 Create and complete quests
- ⭐ Earn XP and points
- 📈 Level up your character
- 🎁 Unlock rewards
- 🛍️ Shop system
- 🧙 Character progression
- 🎉 Level-up celebrations
- 🎮 RPG-inspired interface

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS
